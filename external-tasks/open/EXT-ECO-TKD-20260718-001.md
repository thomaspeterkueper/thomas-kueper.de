# EXT-ECO-TKD-20260718-001 — Verlinkung auf vier neue Vertiefungs-Sites

## Anlass

Der Owner hat vier neue Vertiefungs-Sites registriert (ECO-ARC-0016), analog
zu Mishkenaz/Omnizedenz/AVI-Modell: `endia.de`, `zereya.de`,
`fluide-hermeneutics.org`, `resonanceethics.org`. Auf `thomas-kueper.de`
existieren dazu bereits Überblicksseiten.

## Gewünschte Änderung

Vier Verweise ergänzen:

1. `src/content/romane/endia.md` bzw. die zugehörige Anzeige → Verweis auf `endia.de`
2. `src/pages/universen/zereya.astro` → Verweis auf `zereya.de`
3. `src/pages/philosophie/fluide-hermeneutik.astro` → Verweis auf `fluide-hermeneutics.org`
4. `src/pages/philosophie/resonanz-ethik.astro` → Verweis auf `resonanceethics.org`

## Begründung

Macht die im Ökosystem festgelegten Überblick/Vertiefung-Beziehungen für
Lesende sichtbar, wie bereits bei Mishkenaz/Omnizedenz/AVI-Modell umgesetzt.

## Betroffene Repositories

- `thomas-kueper.de` (Verlinkung)
- `endia.de`, `zereya.de`, `fluide-hermeneutics.org`, `resonanceethics.org` (Verweisziele)

## Erwartetes Ergebnis

Alle vier bestehenden Seiten verweisen erkennbar auf ihre jeweilige
Vertiefungs-Site.

## Hinweise

Kein Sofortzwang. `davaru.de` erhält keinen entsprechenden Task — auf
`thomas-kueper.de` existiert kein Davaru-Inhalt, auf den verwiesen werden
könnte (Davaru ist in-universe-Konzept, Begleiter zu `endia.de`, nicht zu
`thomas-kueper.de`). Sobald die neuen Sites eine `production_url` haben,
bitte auch der Registry in `kueper-ecosystem` melden (aktuell `null`).
